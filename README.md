# Atlas da Terra-média

Atlas interativo e offline do universo de Tolkien: personagens com retratos, mapa ilustrado com jornadas, Teia Viva de relações, genealogias, cronologia, livros, filmes e jogos. Tem **busca por voz** 🎙️ e **leitura em voz alta** 🔊.

**Abrir no celular:** https://jiomavj-tech.github.io/atlas-terra-media/ (depois que o GitHub Pages for ligado).

É um único arquivo, o `index.html`. Para usar offline, baixe esse arquivo e abra no Chrome.

- A lista de correções, em ordem de prioridade, está em [`TAREFAS.md`](TAREFAS.md).
